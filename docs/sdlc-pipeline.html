FROM IDEA TO PRODUCTION — HOW WE SHIP
Conversational-first PWA

MatMind moves work through five stages, each with a concrete artifact in this repo. AI agents accelerate two of them — story generation and regression QA — but every change still ships behind a written story and passes the QA checklist. Stack: React + Vite PWA, Supabase/Postgres + RLS, Claude Haiku 4.5 on Vercel serverless, SendGrid, Twilio, Web Push.

Who Does What

🧑‍🏫 Product / Coach-owner

  • Owns the backlog & priorities
  • Approves side-effectful tests (email/SMS/invites)
  • Signs off on releases

🤖 Story Agent (Cowork)

  • Feature → structured story
  • Writes acceptance criteria & test cases
  • Flags risks & dependencies

🧪 QA Agent (Cowork)

  • Drives the deployed app
  • Runs the checklist, captures evidence
  • Files bugs, writes the report

Operating Principles

The AI is the app.Conversational-first input; dashboards for context only.
Multi-tenant by default.team_id + RLS on every table; isolation is non-negotiable.
Skill-based groups.Beginner/Advanced are skill tiers, never age brackets.
Confirm before side effects.The AI never sends, posts, or deletes without explicit confirmation.
Verify at the surface.Truth is the running app, observed through its real UI.
Migrations lead code.Schema lands before the code that depends on it.
