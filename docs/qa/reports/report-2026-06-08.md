## Warnings

**⚠️ W-01 — PWA icon files missing from repo (high — repeat from 2026-06-07)**
- `public/` contains only `favicon.svg` and `attendance-mockup.html`. The PWA manifest (and vite.config.js) reference `icon-192.png` and `icon-512.png`, but neither file exists anywhere in the repository. `apple-touch-icon.png` (referenced in vite.config.js `includeAssets`) is also absent.
- Live Vercel deployment serves the manifest correctly — icons may be cached from a prior build. A clean Vercel rebuild or new deployment environment would produce 404s for all PWA icon references, breaking installability.
- File: `public/` (missing), `vite.config.js` line ~28, `src/manifest.webmanifest`
- **Prior report:** This was filed as a High bug on 2026-06-07 (`issue-2026-06-07-PWA-missing-icons.md`) and remains unresolved.
- **Fix:** Add `public/icon-192.png`, `public/icon-512.png`, and `public/apple-touch-icon.png` to the repo.

**⚠️ W-02 — Duplicate athlete in Advanced group (medium)**
- The Roster tab shows "DAK Kalish" appearing twice in the Advanced group with slightly different weights (82 lbs vs 85 lbs, both listed as 5th grade). The AI also reflects this: "Advanced: 2 athletes (DAK Kalish × 2)".
- This is likely a duplicate database row (two athletes with the same name in the same group). Could mislead coaches on roster counts and weight class assignments.
- Visible in Roster tab → Advanced filter; confirmed via AI-02 response.
- **Fix:** Review the `athletes` table for duplicate rows; de-duplicate or clarify if these are two different athletes sharing a name.

**⚠️ W-03 — Build fails in QA sandbox (environment issue, low)**
- `npm run build` fails in the Linux QA sandbox with: `@esbuild/darwin-arm64 package is present but @esbuild/linux-arm64 is needed`. This is a node_modules platform mismatch (installed on macOS, synced to Linux). Not a code bug; the live Vercel deployment builds and runs correctly.
- **Fix:** Run `npm ci` on Vercel's Linux build environment; do not copy `node_modules` across platforms.
